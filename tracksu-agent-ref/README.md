scope, commit plan, результаты проверок, решения и следующий шаг, не копию плана.

## Как поддерживать комплект

Одна тема — один документ-владелец; остальные ссылаются на него. Не возвращать
зеркало в repo и не складывать новые пожелания в конец каждого файла. После
checkpoint обновить карточку и строку очереди, затронутый стандарт — при изменении
самого правила. README приложения/CHANGELOG и версионируемая техническая
документация появятся по P02.1: это другой артефакт, не копия подготовки.

Комплект — часть репозитория и должен попадать в отдельные плановые коммиты
вместе с изменением своего состояния. Код, подписи и секреты в нём не храним.
