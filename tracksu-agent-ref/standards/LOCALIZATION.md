# Локализация Tracksu

Источник формата — [официальное руководство Flutter](https://docs.flutter.dev/ui/internationalization),
не примеры ARB из TSD. Это прямое решение пользователя от 2026-09-06.

## Каталоги и контракт

- `lib/l10n/app_en.arb` — шаблон: сообщение и соседний `@key` с `description`.
  Для параметров задаём `placeholders`, типы и нужные `format`/`optionalParameters`.
- Остальные `app_<language>.arb` — `@@locale` и переводы тех же ключей.
  Метаданные шаблона не дублируем. Имена параметров не переводим.
- Целые фразы вместо склейки; ICU plural/select — когда от значения зависит
  грамматика. Не вводим искусственные plurals для подписей вида «Количество: N».
- Числа/даты форматируем по locale, идентификаторы не группируем. `scoresPlayedAt`
  получает уже локализованные дату и время из `DateFormat`; это не сырая дата API.
- `fvm flutter gen-l10n` — единственный способ обновить generated output.
  `required-resource-attributes: true`; описания нужны и простым сообщениям.
  Отчёт `l10n_untranslated.json` игнорируется Git и должен быть пустым `{}`.
- `AppLocalizations.supportedLocales` используется приложением и контроллером.
  English стоит первым через `preferred-supported-locales`, это fallback.

## Поддерживаемый объём

Семь языков: en, ru, de, fr, es, ja, zh. zh содержит только упрощённое письмо;
при системном традиционном китайском языковой fallback тоже покажет этот каталог.
Не заявляем отдельную поддержку Traditional Chinese или региональных вариантов.
Выбор языка и system сохраняются существующим LocaleStore без миграции схемы.
При добавлении ключа обновляем все семь каталогов. Меню языка находится в
`guest/widgets/account_actions.dart`; при добавлении языка обновляется и оно.

Переводим UI приложения, не внешний OAuth-сайт, пользовательские имена,
названия карт/режимов/модов, страны из API или содержание новостей. Переводы
новых языков пока без редакторской проверки носителями: перед release нужна
проверка терминологии и длинных подписей на телефоне. Assets и темы не меняем.
Техническая генерация/analyze/build не заменяет ручную языковую приёмку.
