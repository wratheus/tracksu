  тот же `UiSegmentedControl`, что в профиле, синхронизирован со свайпом.
- Авторы: Repentance — автор (osu! 12288747), Sgooll — соавтор
  (osu! 24581198). Тап открывает профиль внутри приложения.
- История — таймлайн трёх версий и блок благодарностей. Первая версия —
  2021, третья (текущая) — 2026. **Год и содержание второй версии не
  уточнены**: сейчас нейтральный текст без года — заменить, когда
  пользователь даст факты.
- «Настройки» — сгруппированный список в духе системных настроек.

## Что сделано

- UI kit (`tile.dart`): `UiTile.value` (значение справа + шеврон),
  `UiTileIcon` (иконка в тонированном квадрате), `UiListGroup` (подпись
  группы, строки на одной карточке с отступными разделителями, сноска).
- Настройки: шапка аккаунта (гость / вошёл), группы «Аккаунт»,
  «Оформление» (язык, тема — значение справа), «Загружать изображения»,
  «Кэш» (размер справа, пояснение — сноской), «О приложении», выход.
  Pull-to-refresh пересчитывает кэш, прогресс — линия под app bar (P32).
- О приложении: вкладка «Приложение» (название, описание, версия бейджем,
  ссылки GitHub и osu.ppy.sh, сноска о неофициальности); «Авторы» с
  аватарами из публичного CDN osu! (`a.ppy.sh/{id}`); «История» —
  таймлайн с годами и благодарности; «Лицензии» — встроенный
  `LicensesView` (тот же экран, что маршрут `…/licenses`).
- 16 новых строк во всех семи ARB.

## Проверка пользователем

- Настройки: строки читаются как «Тема ……… Тёмная ›», сноска под кэшем,
  pull-to-refresh, выход внизу.
- О приложении: свайп между вкладками синхронен с переключателем; тап
  по автору открывает профиль; поиск в лицензиях.
