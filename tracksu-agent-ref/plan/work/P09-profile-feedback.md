# P09 — обратная связь по профилю, 2026-09-08

Уточнение после 5287774: text-only «О себе» недостаточно. Общий расширенный
renderer с картинками/форматированием/disclosures описан в
[P07-rich-content](P07-rich-content.md). Ограничения ниже описывают существующий
baseline, а не окончательный целевой UX user page.

Baseline d70f8f8: analyze/main/catalog debug прошли, пользователь показал
перенос mania, слишком крупные вторичные метрики и неудобный reselect.
Локальная правка .gitignore принадлежит пользователю, в срез не включается.

## Текущий срез: UX общих компонентов

- Ui kit: слитный однострочный selector с иконками/подписями, скошенным
  индикатором, tap/drag-to-select. На узком экране/крупном шрифте остаются
  иконки с tooltip и полной accessibility-подписью, не вторая строка.
  Drag подтверждает выбор по отпусканию, не запускает API на каждом движении.
- UiMetric.compact и UiMetric.row: вторичные показатели меньше основных,
  узнаваемые декоративные иконки, полные локализованные числа и названия.
  Никакого глобального уменьшения text scale ради вмещения.
- Повторный tap активной нижней вкладки возвращает её root, другая вкладка
  открывает сохранённый стек. Root не сбрасывает фильтры/scroll и не refetch.
  Это явно заменяет прежнее решение пользователя о no-op reselect.
- Выбор языка: существующие PNG-флаги плюс текст, системный — иконка устройства;
  флаг декоративный, не единственный идентификатор языка/доступности.

Критерии: общие owners, theme/light/dark, семантика и масштабирование;
format/analyze/main/catalog debug, без автотестов/установки. Пользователь
проверяет touch/drag/Back и визуал на телефоне. Откат — revert, storage не меняется.

Дополнение пользователя в этом же срезе: PP/ranks получают семантические цвета,
селектор — shape-aware ink и лёгкую полупрозрачную подсветку без BackdropFilter.
Профиль получает «О себе» из page.html (серверный результат BBCode), с raw
текстом как явно упрощённым fallback. Общий HTML allowlist извлекается из news,
repository санитизирует, domain хранит безопасный контент, widget показывает
его ленивыми slivers. Изображения/embeds/styles/script запрещены, ссылки только
HTTPS через внешний браузер. Пустой page скрыт, слишком сложный/большой page
не ломает остальную статистику; ссылка на оригинал остаётся.

## Следующие срезы, не потерять

1. P10 scores → P10/P12 карты: восстановить data projection cover/BPM/длительности/
   сложности/mapper/status/favourite_count/play_count. В списке — компактная
   обложка/миниатюра и читаемый текст вне неё; без обложки тот же полезный
   контент, не пустая плашка. Расширенный hero — на деталях. Не прятать
   показатели ради изображения; без N+1 на каждую карточку. BPM/duration/diff
   относятся к конкретной сложности, likes/plays набора не подменяют её данные.
   У набора без выбранной сложности — честный диапазон/набор, не случайная дифа.
2. P09 графики: спокойная линия рейтинга, лёгкая заливка, минимум точек-маркеров,
   читаемая выбранная точка/начало/конец. Референс — направление, не основание
   придумать 90 дней или Today. Сглаживание не создаёт ложных экстремумов и
   не соединяет пропуски. Отдельный помесячный график просмотров реплеев.
3. P09 друзья собственного аккаунта: после согласования friends.read/re-consent,
   отдельная приватная секция и очистка при logout/account switch, без доступа
   к списку друзей произвольного игрока и без кнопок add/remove.

## Проверенный API, не реализация этих функций

[osu! API](https://osu.ppy.sh/docs/index.html), проверено 2026-09-08:
GET /friends требует user OAuth и friends.read. Текущего public/identify
недостаточно; POST/DELETE friends помечены lazer и не обещаются клиенту.
Get User включает replays_watched_counts: элементы start_date/count (пример
помесячный). Это история просмотров записей игрока другими, не просмотренные
им самим реплеи. Отдельно scores type=most_replayed — список результатов,
не тот же график и не обещание поддержки без сверки Score контракта.
Scopes, токены и сетевые модели текущим UX-срезом не меняются.
Дополнение «О себе» расширило только page-проекцию прежнего Get User;
новых endpoint/scopes нет.

## Итог проверки

- UiSegmentedControl/UiMetric.compact/row используются в профиле и ручном
  каталоге; режимы также заменены через общий OsuRulesetSelector на SearchHome.
- Shape-aware ink, tonal translucent gradient (без настоящего backdrop blur),
  флаги GB/RU/DE/FR/ES/JP/CN из имеющихся assets; язык не определяется флагом.
- «О себе» по умолчанию свёрнут, раскрытие монтирует sliver HTML; пустой page
  скрывается, raw fallback экранируется. Общий sanitizer/link resolver перенесён
  без совместимого bridge, news использует того же владельца.
- `fvm flutter gen-l10n`: пять ключей во всех семи языках, untranslated `{}`.
- Format и `fvm flutter analyze --no-pub`: No issues found.
- Debug APK каталога `lib/ui_catalog.dart` и main собраны. JDK25 native-access
  warning неблокирующий. Итоговый app-debug.apk — основное приложение.
- `git diff --check` без замечаний. Автотесты не создавались/не запускались,
  приложение на устройство не устанавливалось. Ручной visual/gesture smoke
  обязателен: drag/cancel, disabled, светлая/тёмная тема, крупный шрифт,
  root reselect/Back, flags, About/HTTPS links и новости после общего sanitizer.
- Пользовательская .gitignore не изменялась агентом и не входит в коммит.

Ближайший следующий срез остаётся P10 scores/карты. Визуальный график рейтинга
и помесячные просмотры — отдельная доработка профиля; друзья отложены вместе
с [PRODUCT-FUTURE](PRODUCT-FUTURE.md). Эти функции не отмечать реализованными.
