# P53 — ссылки в приложении и просмотр одной страницы

2026-10-08 · запрос пользователя: ссылки из wiki/новостей/профилей/
комментариев — в приложение; внешние страницы открывать «чисто как
страничку», без свободного перехода по сайтам (ревью сторов).
Решение: [ADR-009](../../decisions/ADR-009-single-page-viewer.md).
Статус: awaiting_manual_check.

## Код

- `_shared/navigation/app_links.dart` — `AppLinks.open(context, uri)`:
  wiki / профиль (с режимом и без) / набор и сложность карты / команда →
  экраны приложения; YouTube и не-https → системный браузер; остальное →
  `openWebPage`.
- `_shared/navigation/external_links.dart` — только
  `ExternalLinks.openInBrowser` (системный браузер, явное действие).
- `web_page/screen.dart` — `WebPageScreen`: заголовок + хост, «Поделиться»
  (`ShareTarget.webPage`), линия прогресса, ошибка с «Открыть в браузере»;
  навигация основного фрейма после загрузки заблокирована.
- Router: `…/web?url=` в каждой ветке (https, без userinfo, ≤ 4096),
  `TracksuAppRouter.openWebPage`.
- Переведены: комментарии, changelog, «О приложении», детали профиля,
  статья новости, блоки контента, wiki, команда.
- Changelog: вся строка записи кликабельна (ссылка на PR/коммит или
  раскрытие текста), шеврон — отдельная кнопка «Показать текст».
- 3 строки (`webPage*`) в 7 языках.

## Проверка

GUI — пользователь: ссылка на wiki из новости и «О себе», ссылка на профиль
и карту из комментария, внешняя статья открывается одной страницей, клик по
ссылке внутри неё уходит в Safari, YouTube — сразу в приложение YouTube /
Safari, «Поделиться» на странице.
