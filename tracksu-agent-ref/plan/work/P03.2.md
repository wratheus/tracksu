# P03.2 — modern Android Gradle layer

Статус: `implemented` · 2026-09-04.

## Цель и границы

Заменить Gradle 7.4 / AGP 4.1.3 / imperative Flutter scripts на Android-only
template Flutter 3.47.2. Не менять Dart-код, Flutter packages, UI, OAuth,
production signing или iOS.

## Реализация

- Groovy `settings.gradle`, `build.gradle` и `app/build.gradle` заменены на
  Kotlin DSL (`.gradle.kts`) из Flutter 3.47.2 template.
- Зафиксированы TSD-aligned Gradle 9.7.1, AGP 9.3.2, Kotlin 2.4.10, Plugin DSL,
  JDK/JVM target 21 и explicit `namespace = applicationId =
  io.github.wratheus.tracksu`.
- Сохранены Kotlin MainActivity, `minSdk = 26`, icon, application label,
  Internet permission и Flutter version from `pubspec.yaml`.
- Удалены legacy `apply from`, AGP/Kotlin buildscript classpaths, Java 8,
  `lintOptions`, explicit Kotlin stdlib-jdk7 and old release keystore loading.
- До нового keystore release variant использует template debug signing. Это не
  production signing и не разрешение на публикацию.

## Проверки

- Сгенерирован временный Android-only Kotlin template Flutter 3.47.2 с
  `--no-pub`; его scripts сверены с перенесёнными.
- `android/gradlew :app:tasks --no-daemon --console=plain` завершился с
  `BUILD SUCCESSFUL` на JBR 21, Gradle 9.7.1 и AGP 9.3.2; Flutter Gradle plugin
  сконфигурирован. Flutter SDK выдал собственные Kotlin warnings.
- AGP предупреждает о `android.builtInKotlin=false` и `android.newDsl=false`:
  Flutter plugin всё ещё обращается к legacy variant API. Флаги оставлены
  намеренно и совпадают с переходной конфигурацией TSD; предупреждения не
  подавлялись.
- `git diff --check` пройден.
- `pub get`, Flutter APK/AAB build, analyzer и tests не запускались: packages
  ещё не мигрированы, а tests отложены по решению пользователя.

## Остаток P03

1. Подтвердить совместимые Flutter package versions в P02 и выполнить debug
   build/install вручную после этого.
2. Создать новый production keystore и настроить signing только после готовности
   нового developer account.
3. Отдельно разобрать splash/icon, 16-KB pages, edge-to-edge, external links
