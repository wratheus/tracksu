# P41 — поиск карт

2026-10-05 · implemented in code / awaiting_manual_check.

## Зачем

В приложении можно было открыть карту только из профиля, рейтинга,
новостей или карты дня — поиска по картам не было. Это базовая функция
клиента osu!.

## Контракт

`GET /api/v2/beatmapsets/search` (`BeatmapsetsController@search`,
`require-scopes:public` — гостевой токен подходит). Параметры
(`BeatmapsetSearchRequestParams`): `q`, `m` (0–3), `s` (`leaderboard`,
`ranked`, `qualified`, `loved`, `pending`, `wip`, `graveyard`, `any`;
`favourites`/`mine` — только с входом), `nsfw`, `cursor_string`. Без
пользователя с привилегией `BeatmapsetAdvancedSearch` osu-web
**игнорирует `sort` и расширенный синтаксис** (`stars>5`), поэтому
сортировки в приложении нет; `r` и `played` — только для supporter.
Ответ `BeatmapsetSearchResult`: `beatmapsets` (BeatmapsetExtended),
`cursor_string`, `total`. В официальной документации эндпоинт не описан —
недокументированный контракт, разбор строгий.

## Решение

- `lib/src/beatmap_search`: домен (запрос: текст, режим, статус),
  источник (NSFW скрыт), репозиторий (сеты через `ProfileBeatmapDto`,
  без дублей), `BeatmapSearchBloc` (latest-wins, курсор, без дублей при
  подгрузке), экран.
- Экран «Поиск карт» (`…/beatmaps?q=`): поле поиска (поиск через 0,5 с
  после ввода или по Enter), выбор режима (общий сегментный контрол),
  статус через компактный выбор категории, «Найдено N», карточки как в
  профиле (обложка с превью, факты), бесконечная прокрутка,
  pull-to-refresh и линия под app bar. Тап — страница набора карт.
- Главная: карточка «Поиск карт» под поиском игрока.
- Allowlist: `/api/v2/beatmapsets/search`.
- Тест: `test/src/beatmap_search/beatmap_search_test.dart`.

## Не входит

Сортировки, «любой режим», жанр/язык, расширенный синтаксис — без входа
пользователя osu-web их не применяет (сортировка) или это отдельный срез
(жанр/язык).

## Проверить

- Главная → «Поиск карт»: список ранкнутых osu!, прокрутка, подгрузка.
- Ввод «freedom dive», смена режима и статуса.
- Тап по карте → страница набора; превью играет на карточке.
