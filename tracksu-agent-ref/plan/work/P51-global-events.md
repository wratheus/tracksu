## Размещение

Вкладка «osu!»: Новости / **События** / Изменения — та же свайп-панель.
«Поделиться» на странице событий неактивна: у сайта нет отдельной страницы
глобальной ленты.

## API (osu-web `EventsController@index`, срез 8d395f2)

- `GET /api/v2/events?cursor_string=…` (scope public), 50 событий за раз,
  новые сверху (`sort=id_desc` по умолчанию). Ответ `{events, cursor_string}`;
  пустой/отсутствующий курсор — конец ленты. Добавлено в allowlist.
- События — тот же объект Event, что и `users/{id}/recent_activity`.
  Ссылки относительные или полные: `/b/`, `/s/`, `/u/` и `/users/{id}`.

## Код

- Общий слой событий `lib/src/_shared/events/`: `OsuEvent`/`OsuEventKind`
  (бывш. `ProfileActivity`), `OsuEventDto` (+ `userId` из ссылки игрока),
  `OsuEventRow`. Активность профиля использует его же.
- `OsuEventRow`: в профиле (`medalsOf`) ник не повторяется, медаль ведёт в
  медали; в глобальной ленте строка начинается с ника, медаль, supporter и
  смена ника открывают профиль игрока (режим — из события или osu).
- `lib/src/events/`: `OsuEventsRepository`, `OsuEventsBloc` (первая страница в
  session cache, курсорная подгрузка, ошибка не стирает видимое),
  `OsuEventsSlivers`. Четыре строки в 7 языках.

## Название «osu!» во вкладке

[Brand identity guidelines](https://osu.ppy.sh/wiki/en/Brand_identity_guidelines):
использование не требует согласования; «osu!» пишется строчными, без курсива,
как определяющее слово («osu! community»). Мы называем раздел по источнику
контента, логотип osu! не используем (иконка — компас), в README и «О
приложении» указано, что приложение неофициальное. Это не юридическая
консультация; при публикации в сторах сверить ещё раз.

## Группы событий (2026-10-08, запрос пользователя)

`OsuEventFilter`: Все / Рекорды (rank, rankLost) / Медали (achievement) /
Карты (beatmapPlaycount, beatmapset*) / Supporter и ники (userSupport*,
usernameChange). У `/events` нет параметра типа (только `sort` и курсор),
поэтому фильтр клиентский: загруженная лента не сбрасывается, меняется
только отображение. Если группа на загруженных страницах короткая, авто-
подгрузка в конце остаётся видимой и тянет более старые страницы до конца
курсора. Переключение группы — отдельный обработчик Bloc, не ждёт запроса.
Выбор — компактный `OsuCategoryPicker`, как в результатах и картах профиля.
