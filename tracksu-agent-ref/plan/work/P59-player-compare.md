# P59 — сравнение игроков

2026-10-09 · пожелание пользователя (раньше — в
[PRODUCT-FUTURE](PRODUCT-FUTURE.md)). Статус: backlog (план).

## Данные (public, гостевой токен)

- `users/{id}/{mode}` × 2 — pp, места, точность, плейкаунт, время, грейды,
  уровень, `rank_history`.
- По желанию `users/{id}/scores/best?limit=100` × 2 — пересечение карт,
  на которых есть оба, распределение модов/звёзд.
- Итого 2–4 запроса на сравнение, кэш сессии; без запросов по каждому
  результату.

## Экран

- Вход: из профиля «Сравнить с…» (поиск игрока в шторке), из рейтинга
  долгим тапом / меню строки, из своего профиля «со мной».
- Две колонки с аватарами, режим общий ([ADR-011](../../decisions/ADR-011-global-ruleset.md),
  локальная кнопка), строки метрик с полосой «кто впереди», графики мест
  двух игроков на одном поле, общие карты из топов с pp обоих.
- Честность: одинаковый ruleset и scoring, «нет данных» вместо нулей,
  дата свежести.
