# P07.1 — небольшой набор языков и стандартный ARB

2026-09-06. Пользователь отложил legacy-assets до совместной работы с дизайном.
Текущий срез: en/ru + de/fr/es/ja/zh (упрощённый китайский), без региональных
каталогов и без темизации. zh — базовый китайский каталог с упрощённым письмом,
традиционный перевод не заявляем. Неподдерживаемые языки — English fallback.

Один атомарный commit: полные переводы, ARB metadata в английском шаблоне,
generation config/output, выбор/сохранение языка, документация. Источник правил:
https://docs.flutter.dev/ui/internationalization — выше примеров TSD для ARB.
Descriptions и типы/форматы placeholders хранятся в app_en.arb; переводные
каталоги содержат @@locale и сообщения с теми же ключами/параметрами.
Новые зависимости, серверный перевод, перевод osu! сайта/API-контента,
assets, тема, перенос в пакет и автоматические тесты не входят в scope.

Baseline: en/ru, Flutter gen-l10n, сохранение languageCode через LocaleStore,
generated delegates в MaterialApp. При старте обнаружен пользовательский перенос
guest_shell presentation → widgets и router import. Пользователь отдельно разрешил
включить его в этот commit вместе с меню языков; прочего чужого diff не было.
Проверки: gen-l10n с обязательными resource attributes и отчётом пропусков,
format, analyze lib/packages, debug APK. Не создаём test harness.
Ручная приёмка: все семь языков, system/fallback, сохранение после перезапуска,
длинные подписи, CJK, числа/даты, авторизация и ошибки. Переводы требуют
редакторской проверки носителями перед release; генерация её не заменяет.
Откат: revert этого среза; старые en/ru значения storage совместимы,
неподдерживаемое сохранённое значение после отката даст системный язык.

## Результат

169 сообщений в каждом из семи каталогов (164 существующих и пять названий
языков). Английский шаблон содержит контекст каждого сообщения и существующие
типы/форматы параметров, русский больше не дублирует metadata. LocaleController
использует generated supportedLocales вместо отдельного списка en/ru; storage
контракт неизменен. Меню дополнено пятью языками, существующий дизайн сохранён.

Проверки 2026-09-06: gen-l10n passed, отчёт пропусков `{}`; scoped dart format
passed; analyze lib + оба package lib — No issues found; debug APK (--no-pub)
собран за 9.6s. Прежний JDK native access warning остаётся. Первый gen-l10n
не смог создать вложенную папку для отчёта; путь исправлен на ignored файл
в корне, повторная генерация и сборка успешны. Тесты не писали/не запускали.
Skills UI/Dart/quality определили scoped изменения и generated-code discipline;
ARB policy соответствует прямому запросу пользователя и Flutter documentation.
Устройство и редакторская проверка переводов остаются пользователю.
