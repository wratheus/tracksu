## Размещение

- Навбар: Поиск · Рейтинги · **osu!** (иконка explore). Заголовок экрана «osu!».
- Сверху «Новости / Изменения» — тот же `UiSegmentedControl` со свайпом
  (переключение после половины), как в рейтингах. У каждой страницы свой
  scroll, keep-alive, pull-to-refresh, линия прогресса в AppBar.
- Повторный тап по вкладке навбара прокручивает видимую страницу наверх.
- Статья новости открывается как раньше (`NewsMain(params)` → `NewsScreen`).
  Лента вынесена в `NewsSlivers` и используется и хабом, и экраном статьи.
- Следующие этапы (по одному, после решения пользователя): «События»
  (глобальная лента `/events`) третьей страницей хаба, wiki — вкладкой поиска.

## API (osu-web `ChangelogController@index`, срез 8d395f2)

- `GET /api/v2/changelog?stream=&max_id=&message_formats[]=html`, токен не
  нужен (`RequireScopes::NO_TOKEN_REQUIRED`); добавлен в allowlist
  публичного клиента, чтобы идти тем же путём.
- Ответ: `streams[]` (с `latest_build`, `user_count`, featured первыми),
  `builds[]` до 21 (с `changelog_entries`, `github_user`, `message_html`).
  Следующая страница: `max_id = id последней сборки − 1`, если пришла 21.
- Цвета потоков — `osu-web/resources/css/variables.less`: stable40 #66CCFF,
  beta40 #FFDD55, cuttingedge #EEAA00, lazer #ED1221, tachyon #CE00FF,
  web #8866EE.
- Ссылка «Поделиться»: `osu.ppy.sh/home/changelog[?stream=…]`.

## UI

- Плитки потоков (горизонтально): «Все» + поток, последняя версия, игроки;
  выбранная подсвечена цветом потока.
- Карточка сборки: поток цветом, версия, относительная дата; записи по
  категориям в порядке API. Тип: add (+, зелёный), fix (ключ, жёлтый),
  misc (точка). `major` — жирным. Под заголовком `repo#PR · автор`.
- Тап по записи с текстом раскрывает `message_html` (HtmlWidget), кнопка
  открывает PR/ссылку во внешнем браузере (только https).

## Ссылки внутри приложения и язык API (2026-10-08, запрос пользователя)

- `ExternalLinks.open` (`_shared/navigation/external_links.dart`): веб-ссылки
  открываются во встроенном браузере поверх приложения — SFSafariViewController
  на iOS, Custom Tabs на Android (`LaunchMode.inAppBrowserView`). Свой
  адресный бар, «Готово», без доступа к токенам приложения. YouTube — в своём
  приложении; не-веб схемы и отказ листа — системный обработчик. Подключено:
  changelog, комментарии, статьи, «О себе», команда, группы, «О приложении».
  OAuth и шаринг не трогаем. Свой WebView не выбран: его куки/сессии,
  безопасность и навигацию пришлось бы сопровождать самим.
- Язык API: osu-web `SetLocaleApi` берёт `Accept-Language`, без него — язык
  профиля вошедшего игрока. Теперь `OsuApiHeadersInterceptor` шлёт язык
  интерфейса (`LocaleController.effectiveLanguageCode`: выбор → системный,
  если поддержан → en).
- Смена языка (в настройках или системного при режиме «как в системе»)
  очищает `PageCache`: следующий заход грузит данные на новом языке. Уже
  открытые экраны обновляются потягиванием. Новости и changelog osu! пишет
  только на английском — API их не переводит.
