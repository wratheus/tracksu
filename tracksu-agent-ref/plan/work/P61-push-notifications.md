# P61 — уведомления

2026-10-09 · пожелание пользователя (раньше — в
[PRODUCT-FUTURE](PRODUCT-FUTURE.md)). Статус: backlog (план).

## Ограничения osu!

- Уведомления osu! (`notifications`, websocket `notify.ppy.sh`) требуют
  scope `*`/`chat.read` — сторонним клиентам **недоступны**
  ([P49](P49-api-coverage.md)). Значит, push «как в osu!» мы не получим.

## Этапы

1. **Локальные уведомления без сервера:** напоминание о новой карте дня
   (сброс в 00:00 UTC — расписание известно заранее), «до конца карты
   дня 1 час». Opt-in в настройках, системное разрешение по запросу.
2. **Фоновые проверки на устройстве:** BGAppRefresh (iOS, не гарантирует
   время) / WorkManager (Android, ≥ 15 мин): изменение места игрока,
   выход новой новости/сборки. Один-два запроса за проверку, без циклов.
3. **Серверный push:** только с BFF ([P17](../DETAILS.md#p17)) — APNs/FCM,
   регистрация устройства, подписки, отписка, privacy (P01.3). Отдельное
   решение по Firebase и стоимости.

Каждое уведомление — deep link на экран; ничего не включено по умолчанию.
