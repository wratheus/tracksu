# P01.2 — инвентарь и безопасная чистка assets

2026-09-07 · baseline dfe33f2. Пользователь разрешил удалить лишнее после
перехода на новый UI. Это разрешение на cleanup, не подтверждение лицензий.

## Текущий срез

Поиск по lib/packages/android/pubspec показал отсутствие consumers:
15 PNG модов, 8 PNG grades (теперь кодовые badges), старый MyFlutterApp.ttf,
10 utils: triangle.gif, 512х512.png, cloud_logo.png, heart-solid.png,
notification.png, play-circle-solid.png, search.png, transparent_trigen.png,
transparent_trigen_phone.png, yellow_star.png.

Всего **34 файла / 6 256 733 байта / 5,967 MiB** исходных assets. Это не
измеренное уменьшение APK: zip-компрессия и другие build inputs отличаются.
Старый `lib/src/utils/color_contrasts.dart` (Palette) также не имеет consumers.
Удаление адресное; восстановление из Git до cleanup-коммита, без сброса дерева.

## Что остаётся и почему

| Группа | Решение | Проверка дальше |
| --- | --- | --- |
| 225 flags | Keep: OsuCountryFlag, динамический код страны | Источники/лицензия, корректные пропорции; не удалять по отсутствию буквального имени файла |
| 4 mode icons | Keep: OsuRulesetIcon, все четыре режима | Источники, возможная оптимизация/вектор после согласования, не замена случайными иконками |
| Exo 2 regular/italic | Keep: активная theme, OFL notice добавлен в P22 | Точный provenance локальной сборки; metadata/OFL проверены, binaries не менялись |
| painted_logo + 1024x500_banner | Keep: ручной каталог | Это локальный preview, не готовый новый branding |
| countries.json | Keep as source data, исключить из app bundle пока consumer отсутствует | Проверить полноту/названия для будущего поиска страны; не считать JSON источником локализации всех стран |
| Android res/mipmap/cloud_logo и launcher | Keep: native launch references | Отдельный branding/splash этап; это не удаляемый Flutter assets/utils/cloud_logo |

Pubspec регистрирует только нужные каталоги и два точных utils-пути, чтобы
новый случайный файл в utils не попадал в приложение автоматически.
Не удаляем текущие UI kit компоненты, только потому что одна из страниц ещё
не подключила их. Не трогаем токены, keystore, native signing и пользовательские данные.
