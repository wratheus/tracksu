# P60 — виджеты на экране блокировки и домашнем экране

2026-10-09 · пожелание пользователя. Статус: backlog (план; зависит от
[P37](P37-ios-oauth-callback.md) — Team/подпись для App Group).

## Что показывать

- **Мой профиль:** место/pp/изменение за сутки (accessory-виджеты lock
  screen: круглый — место, прямоугольный — pp и место в стране).
- **Карта дня:** обложка, название, сколько осталось (home screen
  small/medium; lock screen — оставшееся время).
- Тап открывает нужный экран через deep link (`AppLinks`).

## Как

- iOS: WidgetKit extension (SwiftUI), App Group для общих данных,
  `home_widget` во Flutter для записи снимка и перезагрузки таймлайна;
  обновление по бюджету системы (несколько раз в час максимум), плюс при
  открытии приложения.
- Android: App Widget (Glance/RemoteViews) через тот же `home_widget`,
  WorkManager для периодического обновления (≥ 15 мин).
- Данные: только из уже сделанных запросов приложения (снимок), фоновое
  обновление — один запрос профиля и/или `rooms?category=daily_challenge`.
