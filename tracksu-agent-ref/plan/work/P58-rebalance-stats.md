# P58 — статистика после ребаланса (pp rework)

2026-10-09 · пожелание пользователя. Статус: backlog (план, нужен выбор
источника данных).

## Задача

После пересчёта pp (deploy нового difficulty/performance calculator)
показать: как изменились pp и места игрока, какие его результаты выросли
или упали, общие тренды (какие моды/карты подняли).

## Что есть в API

- Только **текущие** значения: `users/{id}` (pp, rank, `rank_history` за
  90 дней — места, не pp), `scores/best` (100 лучших с текущими pp).
- Истории pp отдельных результатов «до/после» в API нет; новости osu! с
  тегом пересчёта — только текст.

## Варианты источника «до»

1. **Локальные снимки на устройстве:** при открытии своего (или
   избранного) профиля сохранять компактный снимок (pp, rank, топ-100
   `score_id → pp`), раз в N дней. После ребаланса — диф с последним
   снимком до даты деплоя. Без сервера, но только для тех, кого
   пользователь смотрел раньше.
2. **BFF ([P17](../DETAILS.md#p17))** хранит снимки для подписанных
   игроков — шире, но сервер и privacy (P01.3).
3. **Сторонние симуляторы (huismetbenen и др.)** — неофициально, только
   ссылка/по решению.

Дата ребаланса: вручную по новостям osu! или по скачку pp у многих
снимков. Рекомендация: вариант 1, экран «Изменения после пересчёта» в
профиле, честная пометка, с какого снимка сравнение.
