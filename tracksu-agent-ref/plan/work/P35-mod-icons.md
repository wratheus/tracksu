# P35 — официальные иконки модов везде

2026-10-04 · implemented in code / awaiting_manual_check.

## Решение пользователя

Иконки модов — только официальные (osu!), маленькие, рядом с названием,
во всём приложении. Пользователь подтвердил использование ресурсов ppy
с указанием авторства.

## Источник и лицензия

- `ppy/osu-resources`, коммит `e4010bddabce61374aacfa676d0175d5788b14b4`
  (2026-09-29): `osu.Game.Resources/Textures/Icons/Mods/*.png` — 70 глифов
  (белые, 120×84) и `Icons/BeatmapDetails/mod-icon(.png|-extender.png)` —
  форма шестиугольника (135×100, 194×100). Это те же файлы, что рисует
  osu!lazer.
- Файлы положены в `assets/icon_mods/` **байт в байт** (Git blob SHA-1
  совпадают с деревом коммита, проверено для всех 72), у глифов убран
  префикс `mod-`. Лицензия osu-resources — CC BY-NC 4.0, как у флагов (P27):
  notice `assets/licenses/osu_mod_icons.txt`, зарегистрирован в
  `registerAssetLicenses` («osu! mod icons» на странице лицензий).
- Почему не по URL во время работы: raw.githubusercontent.com — не CDN для
  приложений (лимиты, нет гарантий доступности), иконки нужны офлайн и в
  списках сотнями; вшитые файлы закреплены на коммите и проверяемы.
  Обновление — заменить файлы из нового коммита и поправить notice.
- Перенос: файлы скачаны встроенным браузером одним JSON в «Загрузки»
  пользователя (`tracksu-mod-icons.json`, можно удалить) и разложены
  скриптом.

## Реализация

`lib/src/_shared/ui/osu_mods.dart` (реэкспорт из `osu_badges.dart`):

- `OsuModInfo` — таблица акронимов osu!lazer → официальное название
  (англ., как в игре), тип и файл глифа. Типы и цвета — `OsuColour.ForModType`
  (снижение #B2FF66, повышение #FF6666, конверсия #8C66FF, автоматизация
  #66CCFF, fun #FF66AB, системные #FFCC22).
- `OsuModIcon` — форма, тонированная цветом типа, и тёмный глиф поверх,
  как в lazer; высота 16. Неизвестный акроним — серая форма без глифа.
- `OsuMods` — компактные чипы «иконка + акроним», полное имя во
  всплывающей подсказке и в семантике. «Без модов» — иконка No Mod.
- Используется везде, где раньше были текстовые бейджи: карточки игр
  (профиль, лидерборд карты), лист деталей скора, карта дня, каталог UI.

Тест: `test/src/_shared/ui/osu_mods_test.dart` (таблица, наличие файлов,
неизвестный мод, пустой список, семантика).

## Проверить

- Скоры в профиле и на карте: HD/HR/DT/NC/FL/CL и моды lazer (DA, TC, AC…).
- Карта дня: обязательные моды.
- Тёмная и светлая темы; крупный шрифт — чипы переносятся.
- О приложении → Лицензии → «osu! mod icons».
