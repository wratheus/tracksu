# P39 — комментарии к новостям и картам

2026-10-04 · implemented in code / awaiting_manual_check.

## Запрос пользователя

Комментарии у новостей и карт: бесконечная прокрутка, ответы, рейтинг
(голоса), переход в профиль — «базовые вещи».

## Контракт

`GET /api/v2/comments` — документирован («Get Comments» → CommentBundle),
открыт гостю (`CommentsController`: `auth` except index/show; public
scope). Параметры: `commentable_type` (`news_post`, `beatmapset`),
`commentable_id`, `parent_id` (0 — верхний уровень), `sort`
(`new`/`old`/`top`), `limit` (≤100, у нас 50), `cursor[...]` — объект
`cursor` из ответа как есть. Ответ (osu-web `CommentBundle`): `comments`
(запрошенный уровень), `included_comments` (до двух уровней ответов к ним),
`pinned_comments`, `users` (UserCompact), `has_more`, `cursor`, `total`.
Комментарий (`CommentTransformer`): `id`, `parent_id`, `user_id`, `pinned`,
`replies_count`, `votes_count`, `legacy_name`, `created_at`, `edited_at`,
`deleted_at`, `message_html`.

## Решение

- `lib/src/comments`: домен, источник, репозиторий (строгий разбор;
  `message_html` очищается: картинки/видео/iframe не грузятся — картинка
  становится ссылкой), `CommentsBloc` (latest-wins по сортировке, страницы
  без дублей, ответы по родителю со своим курсором), виджеты.
- `CommentsSection` (sliver): заголовок с числом, сортировка «Новые /
  Старые / Лучшие» (общий сегментный контрол), закреплённые сверху,
  автоподгрузка следующей страницы, ответы по кнопке «N ответов»
  (с подгрузкой «Ещё ответы»), голоса, относительное время, «изменён»,
  удалённые — плейсхолдер. Аватар и ник открывают профиль; ссылки на
  профили osu! внутри текста тоже открываются в приложении. Pull-to-refresh
  через `PageRefreshTarget`, где у страницы есть `PageRefreshScope`.
- Новость: секция под статьёй. Карта: внизу переключатель «Результаты /
  Комментарии» (заголовок «Результаты» у лидерборда убран — его заменяет
  переключатель); комментарии грузятся при первом открытии вкладки.
- Allowlist: `/api/v2/comments`.
- Не входит: написание, голосование и жалобы (нужен вход пользователя со
  scope и отдельное решение), комментарии changelog.

## Тесты

`test/src/comments/comments_test.dart`: разбор бандла (ответы, пользователи,
курсор, картинки → ссылки, удалённые), подгрузка страниц и ответов без
дублей.

## Проверить

- Новость с комментариями: сортировки, прокрутка до конца, ответы, профиль.
- Карта: «Комментарии», возврат на «Результаты», pull-to-refresh.
