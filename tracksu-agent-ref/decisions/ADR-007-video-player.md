# ADR-007: видео в статьях — `video_player`

2026-10-04 · принято (запрос пользователя «могли бы поддержать и видео
плеер»).

## Контекст

В новостях osu! регулярно есть `<video>` с файлами `assets.ppy.sh`
(showcase Featured Artist и т. п.: 37 видео в последних 60 постах 2025
года по исходникам ppy/osu-wiki) и `<iframe>` YouTube/Twitch/Google Docs
(63 в тех же постах). До этого всё показывалось как «вставка доступна на
исходной странице». `just_audio` видео не рисует; WebView ради плеера —
тяжёлая зависимость и чужой код на странице.

## Решение

- Добавить `video_player` (flutter.dev, iOS AVPlayer / Android ExoPlayer;
  minSdk 24 ≤ нашего 26, iOS 13 ≤ 15). Только для файлов
  `https://assets.ppy.sh/…(.mp4|.m4v|.mov)` (`ContentVideo.resolve`).
  Загрузка начинается по нажатию «Смотреть видео»; запуск видео
  останавливает аудио статьи; уход со страницы, вкладки или из приложения —
  пауза. Полноэкранный режим — тот же контроллер на чёрной странице.
  Загрузка видео подчиняется той же настройке внешних медиа, что и
  картинки.
- `<iframe>` не встраиваются: YouTube — карточка с превью (`i.ytimg.com`,
  тоже по настройке картинок) и «Смотреть на YouTube» (watch-ссылка
  открывается в приложении YouTube или браузере); прочие — «Открыть на
  {host}».

## Последствия

- После изменения pubspec нужен `fvm flutter pub get` (регистрирует
  нативный плагин для iOS/Android), затем сборка.
- Новая нативная зависимость: при обновлении Flutter проверять плагин.
