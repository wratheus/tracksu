# P03.1 — применить выбранную Android identity

Статус: `blocked by P02` · 2026-09-04. Identity checkpoint выполнен;
следующий Android шаг зависит от pinned toolchain.

## Цель

Перевести текущий Android host на выбранный ID
`io.github.wratheus.tracksu`, не смешивая это с обновлением Flutter, Gradle,
подписью или feature-кодом.

## Scope

- `android/app/build.gradle`: `applicationId`.
- Main/debug/profile manifests: legacy manifest package.
- `MainActivity.kt`: Kotlin `package` и физический путь.
- Точечная документация P03 и дорожная карта.

## За рамками

- Gradle/AGP/Kotlin/JDK upgrade, plugin DSL, SDK levels и новый Flutter template.
- Explicit Gradle `namespace`: текущий AGP 4.1 legacy; введём после P02 в
  clean rewrite P03.2, где namespace и applicationId закрепим одинаковыми.
- New keystore, Play account, OAuth, app label/assets, iOS и Dart-код.
- Build/analyzer/format/test: выбранный SDK/toolchain ещё не закреплён; tests
  исключены из текущей программы.

## Изменение

Старый legacy ID `com.sgoollreps.tracksu` заменён в активных Android identity
points на `io.github.wratheus.tracksu`. Kotlin MainActivity перемещён в
`src/main/kotlin/io/github/wratheus/tracksu/` и объявляет этот package.
Исторические упоминания старого ID в inventory/docs намеренно сохранены.

## Проверки

- Проверить, что ни один production Android source/config не содержит старый ID.
- Проверить отсутствие нового ID вне ожидаемых Android identity points.
- `git diff --check`; вручную просмотреть rename MainActivity и три manifests.
- Не утверждать, что приложение собирается: этот checkpoint намеренно предшествует
  P02/P03.2, а текущая toolchain не проверялась.

## Commit plan

1. `chore(android): apply new application identity` — этот checkpoint.
2. P02: выбрать/pin Flutter, Dart, JDK и совместимые tooling versions.
3. P03.2: clean modern Android template/Gradle rewrite, explicit namespace,
   Kotlin host, новая подпись и platform config — отдельными последующими commits.

## Возврат и следующий шаг

Откат identity — адресный revert этого commit; возвращать legacy iOS или старую
подпись он не должен. После завершения commit перейти к P02 compatibility
inventory, не начинать Gradle rewrite без выбранного toolchain.
